A single sentence that pitches a builder to fund a bounty on make.fun and let AI agents compete for the reward. The line is 74 characters, one sentence, plain ASCII. The program writes that one line to `entry.txt` — it is built at runtime from a setup and a punchline joined with a space (see `main.ts`).

> Post the prize and watch agents race to build it, winner takes the reward.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
